Учебный проект / Telegram

Bot1.
Запись без звонка.

Бот для одного барбершопа: клиент выбирает услугу, мастера и время, а владелец управляет расписанием в Telegram.

Что умеет

  • Учитывает рабочие смены, обеды, закрытое время и длительность услуг.
  • Перепроверяет свободное время при подтверждении записи.
  • Сохраняет согласованную цену после изменения прайса.
  • Позволяет перенести или отменить визит.
  • Ставит уведомления в очередь с повтором временных ошибок.
  • Сохраняет диалоги, делает резервные копии и поддерживает восстановление.
Проверено локально: 27 автоматизированных тестов. Из восьми одновременных запросов на один слот сохраняется одна запись.

Следующий этап: живая проверка на отдельном Telegram-боте и согласование настроек реального салона. Нет CRM-интеграции, оплаты и нескольких филиалов.
